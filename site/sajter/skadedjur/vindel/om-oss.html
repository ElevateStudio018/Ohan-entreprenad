Om Vindel

Hedvig Marklund doktorerade på myrors bobyggande vid Umeå universitet och startade Vindel 2013, när ett bostadsbolag på Ålidhem ringde institutionen om faraomyror som ingen fick bukt med. Hon insåg att problemet inte var giftet utan att ingen visste var samhällena satt.

Vilka vi är

Vi rör inte råttor – vi artbestämmer, kartlägger och utrotar kackerlackor, faraomyror och silverfisk i hela trappuppgångar.

Hedvig Marklund doktorerade på myrors bobyggande vid Umeå universitet och startade Vindel 2013, när ett bostadsbolag på Ålidhem ringde institutionen om faraomyror som ingen fick bukt med. Hon insåg att problemet inte var giftet utan att ingen visste var samhällena satt.

I dag är vi tolv anställda i lokalen på Formvägen, varav elva tekniker som alla har gått Hedvigs interna kurs i artkännedom. Vi arbetar bara med insekter och kvalster, och ungefär sju av tio uppdrag gäller flerbostadshus där problemet har vandrat genom väggar och stammar.
